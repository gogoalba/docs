**Portix 是一层面向生产 AI 系统的基础设施。** 你可以先从模型网关开始，再接入 WebSearch 这类托管工具，以及团队已经在使用的 Agent 框架和编码助手。

## 痛点

每个 AI 厂商都有自己的 SDK、API 格式和鉴权方式。在 OpenAI、Anthropic、Gemini 之间切换意味着重写集成代码、管理多套 API Key、承受厂商锁定的风险。

## 网关兼容层

Portix 在网关层提供**原生协议转换**。你现有的代码原封不动 —— 只需改一个 Base URL。

<Columns cols={3}>

  <Card title="用 Anthropic SDK" icon="arrow-right-arrow-left">

  <Card title="用 Gemini SDK" icon="arrow-right-arrow-left">

<Tabs>
  <Tab title="OpenAI SDK → Claude">
    ```python
    # 用 OpenAI SDK 调用 Claude
    from openai import OpenAI
    
    client = OpenAI(
        api_key="YOUR_API_KEY",
        base_url="https://api.portix.ai/openai/v1"  # ← 只改这一行
    )
    
    response = client.chat.completions.create(
        model="claude-sonnet-4-6",  # ← 用任意模型
        messages=[{"role": "user", "content": "你好！"}]
    )
    ```
  </Tab>
  <Tab title="Anthropic SDK → Gemini">
    ```python
    # 用 Anthropic SDK 调用 Gemini
    import anthropic
    
    client = anthropic.Anthropic(
        api_key="YOUR_API_KEY",
        base_url="https://api.portix.ai/anthropic"  # ← 只改这一行
    )
    
    message = client.messages.create(
        model="gemini-3-flash-preview",  # ← 用任意模型
        max_tokens=1024,
        messages=[{"role": "user", "content": "你好！"}]
    )
    ```
  </Tab>
  <Tab title="Gemini SDK → GPT">
    ```python
    # 用 Gemini SDK 调用 GPT
    from google import genai
    
    client = genai.Client(
        api_key="YOUR_API_KEY",
        http_options={"base_url": "https://api.portix.ai/gemini"}  # ← 只改这一行
    )
    
    response = client.models.generate_content(
        model="gpt-5.4",  # ← 用任意模型
        contents="你好！"
    )
    ```
  </Tab>
</Tabs>

## 你将获得

- **通用 SDK 兼容** —— OpenAI、Anthropic、Gemini SDK 可互换使用，访问 50\+ 模型
- **原生协议转换** —— 不是简单代理：完整的请求/响应格式转换，支持流式、工具调用、视觉和思维链
- **企业级路由** —— 高并发网关，自动故障转移和负载均衡
- **托管工具能力** —— 通过统一账号接入 WebSearch 等独立工具能力
- **面向 Agent 的集成** —— 让现有的编码助手与框架通过 Portix 路由运行
- **零厂商锁定** —— 改一行代码就能切换供应商，集成代码完全不变
- **按量付费** —— 无订阅、无最低消费，用多少付多少
